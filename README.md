# yuzu-ui

Vite-built SPA for Yuzu Companion ecosystem. Multi-page vanilla ES modules.

## Pages

- `index.html` (Home / Redirect)
- `login.html` (Login / Auth)
- `chat.html` (Main chat interface)
- `config.html` (BYOK and settings)
- `about.html` (About page)

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Deployment

Deployable as static assets (Cloudflare Pages / Wrangler / Static host).
Target domain: `chat.yuzuki.space`.
